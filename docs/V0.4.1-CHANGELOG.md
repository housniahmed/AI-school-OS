# V0.4.1 — Database Migration & Integration Test Gate

## Goal
Turn the V0.4 production-hardening baseline into a database-backed CI gate that exercises the real PostgreSQL integration path.

## Added
- Versioned Prisma PostgreSQL migration for the current V0.3/V0.4 schema.
- `prisma:migrate:deploy` and `prisma:validate` scripts.
- Real PostgreSQL 16 service in GitHub Actions.
- Migration deployment in CI before application tests.
- Integration tests covering database readiness, authentication, tenant-scoped asset listing and cross-tenant resource isolation.
- API version `0.4.1`.

## Security coverage
The integration suite verifies that an authenticated user from tenant A cannot list or retrieve an asset belonging to tenant B.

## Release gate
A V0.4.1 merge should require a green CI run. Runtime verification is delegated to GitHub Actions because the development environment used during implementation does not provide Docker or npm network access.

## Next

- Add migration drift checks and rollback/backup procedures.

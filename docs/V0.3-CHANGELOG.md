# V0.3 — AI-Ready Operational Core

## Added
- Student and guardian domain foundation
- Finance domain foundation
- Inventory domain foundation
- Asset and QR foundation
- Knowledge document foundation
- Retrieval/search foundation
- AI assistant/provider abstraction
- Controlled AI tool registry

## Security direction
All domain operations remain subject to authentication, authorization and tenant context. AI tools are intended to call domain capabilities rather than arbitrary SQL.

## Validation
This milestone is synchronized as a design/code baseline. Runtime, integration and production-readiness validation must still be executed before release.

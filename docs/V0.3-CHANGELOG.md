# V0.3 — AI-Ready Operational Core

## Synchronized implementation

- React/Vite executive web application
- Express/TypeScript API
- PostgreSQL + Prisma domain model
- JWT authentication
- Database-backed RBAC with tenant context
- Students and guardians
- Assets/equipment register with QR generation endpoint
- Maintenance requests and work orders foundation
- Inventory, thresholds and movements
- Finance summaries, invoices and outstanding balances
- Internal knowledge documents with chunking and lexical retrieval
- Optional OpenAI embeddings
- Permission-aware AI tool registry
- OpenAI Responses API tool-calling loop with local fallback
- Audit events for authentication, mutations and AI tool execution
- Docker Compose for PostgreSQL and Redis

## Important validation status

This milestone is a synchronized development baseline. Static source inspection has been performed, but a complete runtime/build/integration test has not been executed in the current environment because Docker is unavailable and external npm dependency installation is restricted.

# V0.4.1 — Release gate

V0.4.1 is not considered validated until the repository's GitHub Actions CI successfully completes:

1. PostgreSQL service startup.
2. Prisma schema validation.
3. Versioned migration deployment.
4. API TypeScript build.
5. Authentication and tenant-isolation integration tests.
6. Frontend production build.

A static review is useful but is not a substitute for this runtime gate.

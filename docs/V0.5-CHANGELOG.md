# V0.5 Changelog

## Security & Observability Core

### Added
- Redis 7.4 runtime dependency and healthcheck.
- Redis-backed distributed API rate limiting.
- Dedicated login throttling.
- Structured HTTP request logs with correlation IDs and tenant/user context.
- PostgreSQL + Redis readiness checks.
- Graceful startup and shutdown.
- Explicit trusted-proxy configuration.
- Integration coverage for Redis readiness and security headers.
- PostgreSQL backup/restore runbook.

### Validation

V0.5 is accepted only after GitHub Actions reports green API and Web jobs on the release change set.

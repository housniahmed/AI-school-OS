# V0.5 Security & Observability

This milestone hardens the operational core before expanding the AI agent.

## Scope

- centralized Redis-backed rate limiting
- stricter authentication throttling
- structured request logging with redaction
- PostgreSQL and Redis readiness checks
- graceful startup and shutdown
- explicit proxy/security configuration
- authentication telemetry
- integration tests for security boundaries
- operational backup/restore runbook

## Release gate

The API and Web GitHub Actions jobs must both be green before merging the milestone.

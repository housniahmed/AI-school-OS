# V0.4 — Production Core

## Goal
Strengthen the V0.3 foundation before adding more business domains.

## Added
- App factory (`createApp`) separating application construction from process startup.
- Request correlation through `x-request-id`.
- Explicit 404 responses.
- Readiness endpoint at `/health/ready` with database dependency check.
- Production validation for JWT secrets.
- Node test runner coverage for production configuration rules.
- GitHub Actions CI for API generation/validation/build/tests and frontend build.
- API version updated to `0.4.0`.
- Current OpenAI API model example aligned with the GPT-5.6 model family.

## Validation status
CI configuration is added but has not been executed in this environment. Runtime validation remains a required release gate.

## Next
- Add a real PostgreSQL migration history.
- Add API integration tests.
- Add structured logging and observability.
- Add rate limiting and abuse protection.
- Add backup/restore and operational runbooks.

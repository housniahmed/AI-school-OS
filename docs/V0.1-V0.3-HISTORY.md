# AI School OS — Development History

This file records the milestones discussed and implemented before Git synchronization.

## V0.1 — Product Foundation

Defined the product as a Moroccan-first AI-powered school operating system rather than a generic school ERP. Established the MVP domains, multi-tenancy, RBAC, auditability and the controlled AI-tool architecture.

## V0.2 — Secure Operational Core

Introduced JWT authentication, database-backed permissions, tenant isolation, executive dashboard concepts, assets/equipment, maintenance and audit-oriented workflows.

## V0.3 — AI-Ready Operational Core

Added students/guardians, finance, inventory, QR-coded assets, internal knowledge documents, lexical retrieval, optional embeddings, AI tool registry and an OpenAI Responses API tool-calling provider with local fallback.

## Git synchronization

The GitHub repository was created after these milestones. The repository therefore starts with an initialization history, while the milestones above are documented here rather than represented as synthetic historical commits.
